FAIZ MEDICAL BOARD - 113 x 28 inch

To get a CDR file:
1. Open CorelDRAW -> File -> Import (Ctrl+I) or Open -> pick
   faiz-medical-113x28in-CORELDRAW.pdf  (or the .svg)
   If asked, choose "Import text as: Curves".
2. File -> Save As -> Save as type: CDR.

Layers in the file:
 - Background picture (bottles, pills, crosses, yellow band)
 - Shadow picture (soft shadow under the title and badge)
 - All text = vector curves (no font needed). Gold outline and blue fill
   of the title are separate objects.

To edit wording later, retype with font "Baloo 2" (free, Google Fonts),
weight ExtraBold.

Files:
 faiz-medical-113x28in-CORELDRAW.pdf  -> best for Corel import / printing
 faiz-medical-113x28in-CORELDRAW.svg  -> same design, SVG
 faiz-medical-113x28in-300dpi.jpg     -> flat image, 300 DPI
 faiz-medical-113x28in-100dpi.jpg     -> flat image, 100 DPI
 faiz-medical-113x28in.pdf            -> print PDF (with font embedded)
